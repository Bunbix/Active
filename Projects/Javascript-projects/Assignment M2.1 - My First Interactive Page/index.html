How It Works

This page demonstrates DOM manipulation with JavaScript. Click the buttons below to see different visual effects applied to the squares:

  • Button 1 (Green Square) changes the color to purple
  • Button 2 (Yellow Square) transforms the square into a circle
  • Button 3 (Red Square) makes the square almost disappear with a pink effect

Click the "Reset All Squares" button to restore all squares to their original state.
